# Kutira-Kushala (Self-Employment)  🧺

Kutira-Kushala is a modern, community-driven marketplace designed to empower rural artisans and small businesses. The app provides a platform for sellers to showcase handmade crafts, organic products, and local services to a wider audience, creating a direct connection between producers and consumers.

---

## 🚀 Features

### 👩‍🌾 For Sellers (Rural Artisans)

- Create a personalized digital storefront
- Upload products with multiple images
- Manage retail and wholesale pricing
- Track stock availability
- View production demand insights
- Manage incoming orders
- Connect directly with buyers

### 🛍️ For Buyers (Consumers)

- Discover authentic local products
- Browse products by categories
- Search products using smart filters
- Find women-led and rural businesses
- View recently explored products
- Save and manage cart items

---

## 🌍 Core Experience

- Interactive onboarding experience
- Location-aware product discovery
- Secure login and registration
- Smooth modern UI with Jetpack Compose

## 🏗️ Getting Started

### Prerequisites

- Android Studio Ladybug or newer
- Kotlin 1.9+
- Firebase Project Setup
- `google-services.json` file

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Sanketh360/kutira-kushala.git
```

2. Open the project in Android Studio

3. Add your `google-services.json` file inside:

```text
app/google-services.json
```

4. Sync Gradle and run the project
